# Manu Games

Tienda virtual de videojuegos digitales para el proyecto integrador de Temas Selectos de Tecnología de la Información.

- [Proyecto](Proyecto) contiene el frontend Angular, el servidor Node.js y los scripts de SQLite.
- [Documentos](Documentos) reúne los 13 entregables y su evidencia.

Abre `Proyecto` en Visual Studio Code con Node.js 24. Ejecuta `npm ci` y `npm start` y visita http://localhost:4200. Consulta el [manual de instalación y operación](Documentos/10-Manual-de-operacion.pdf) para configurar la cuenta administrativa y demostrar el recorrido completo.
