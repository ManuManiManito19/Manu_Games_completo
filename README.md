# Manu Games

- [Proyecto](Proyecto/) contiene la aplicación Angular y el backend opcional.
- [Documentos](Documentos/) es la carpeta para los próximos documentos.

## Ejecutar en Visual Studio Code

Abre la carpeta `Proyecto` en VS Code. Con Node.js 24 instalado, ejecuta:

```powershell
npm ci
npm start
```

Luego abre [localhost:4200/inicio](http://localhost:4200/inicio).
